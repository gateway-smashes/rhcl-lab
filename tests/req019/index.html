Motor de Políticas com Expressões CEL

Demonstração de CEL (Common Expression Language) como motor de expressões personalizadas no Kuadrant/RHCL. A AuthPolicy usa predicates CEL para controle de acesso contextual na aplicação bancária.

Expressões CEL demonstradas

request.method == 'POST' request.path.startsWith('/api/v1/transfers') request.headers['x-cel-strict'] == 'true' !request.headers['user-agent'].contains('bot') && || ! 
   browser ──TLS──► Router ──► Gateway/Envoy ──ext_authz──► Authorino
                                    │                           │
                                    │             CEL predicates avaliam:
                                    │               method + path + headers
                                    │               em expressões compostas
                                    ▼
                               200 ou 403
Pré-requisito: aplicar tests/req019/manifests/01-cel-custom-expressions.yaml no cluster. Remover a AuthPolicy de API Key existente se houver conflito.
