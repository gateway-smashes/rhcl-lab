REQ 8

Unified gateway administration console

Item 8 — manage RHCL/Kuadrant gateways across multiple sites and public clouds from a single console using Red Hat Advanced Cluster Management (ACM) on the hub cluster. Details: tests/req008.md.

Scenario

Hub (ACM) ──console/search──► CCT1 / CCT2 / Azure / GCP
                │                    │
                │                    └── Gateway, HTTPRoute, AuthPolicy (per site)
                └── one login, cluster switcher, fleet inventory
Evidence. Add PNG screenshots under tests/req008/manifests/screenshots/ (see filenames below). Paste captures in chat for caption review — synthetic ACM UI images cannot be generated here.

Step-by-step — ACM console

  1. Open the hub OpenShift console.
  2. Go to Infrastructure → Clusters and confirm spokes are Available.
  3. Use the cluster switcher (top bar) → pick a spoke (e.g. CCT1).
  4. Navigate Networking → Gateways → rhcl-apps-gateway.
  5. Open HTTPRoutes in rhcl-apps → banking-api-connectivity.
  6. Switch cluster → repeat on CCT2, Azure, GCP. Same console, different clusters.
  7. (Optional) Search → kind:AuthPolicy → All clusters.

Expected: you administer distributed gateways without a separate login per cloud.

Step-by-step — Terminal

  1. List the fleet on the hub:
oc get managedcluster
oc get multiclusterhub -A
  1. On each spoke (switch kubecontext):
oc get gateway rhcl-apps-gateway -n openshift-ingress
oc get httproute banking-api-connectivity -n rhcl-apps
oc get authpolicy -n rhcl-apps
  1. Optional — confirm traffic on a site (replace hostname):
curl -sk -o /dev/null -w "%{http_code}\n" \
  "https://banking-api-connectivity.poc.rhcl.com.br/api/echo"

Expected: 200 where the route exists; ACM manages the CRs, not the DNS merge.
