Reference design (not implemented in this PoC) for routing **A2A protocol**

a Microsoft product such as Copilot Studio / Azure AI Foundry Agent Service)

## What A2A is

A2A (Agent2Agent) is an open protocol for agent-to-agent communication. On the
wire it is **JSON-RPC 2.0 over HTTPS**:

- Agent discovery via an **Agent Card** at `/.well-known/agent-card.json`
- Synchronous calls via `message/send`
- Streaming via `message/stream` (Server-Sent Events)
- Task lifecycle via `tasks/get`, `tasks/cancel`

Because it is HTTP + JSON-RPC + SSE, RHCL can carry it as ordinary L7 HTTP
traffic. RHCL adds connectivity, TLS origination, observability, and policy at
the transport layer — it does **not** parse A2A messages.
