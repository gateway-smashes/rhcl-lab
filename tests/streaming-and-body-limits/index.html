req026 — File streaming (RHCL body cap)

Generates random bytes locally and sends them to /api/files/upload. The RHCL gateway applies a 32 MiB cap via an Envoy Lua streaming filter (chunk-by-chunk counting, does not buffer the request) + timeout of 60 s via HTTPRoute. Uploads above the cap come back with HTTP 413 and the x-rhcl-streaming-cap headers + x-rhcl-observed-bytes.

cap = 32 MiB timeout = 60 s Expected: 1/25 MiB → 200 with SHA-256. 50 MiB → 413 (RHCL rejection).
