REQ 40

Token counting per route (RHCL-native)

Generate OpenAI-shaped traffic and read authorized_hits / authorized_calls / limited_calls from Kuadrant Limitador (token totals per route). Per-consumer breakdown lives in Grafana dashboard RHCL AI Consumer Access Logs (gateway access log → Loki). No backend Micrometer metric is involved.

Scenario

Browser test page
    │  POST /api/v1/chat/completions    (x-consumer-id + mock_usage)
    ▼
https://banking-api-connectivity.<RHCL_ZONE_ROOT_DOMAIN>/api/v1/chat/completions
    │  HTTPRoute banking-api-connectivity
    │  Envoy access log (JSON) ──► stdout ──► Alloy ──► Loki ──► Grafana consumer dashboard
    │  TokenRateLimitPolicy banking-api-chat-completions-token-limit (REQ 60)
    │       add_n_to_counter(response.body.usage.total_tokens)
    │       └─ authorized_hits{limitador_namespace="rhcl-apps/banking-api-connectivity"}
    │       └─ authorized_calls{...}    /  limited_calls{...} on 429
    ▼
Service banking-api-v1:8080 (Quarkus mock)
    ▲
    │  ServiceMonitor rhcl-limitador-tokens (REQ 40)
    ▼
openshift-user-workload-monitoring/prometheus  ─►  thanos-querier  ─►  Grafana token dashboard
Limitador aggregates token totals per route (no consumer label). Loki captures x-consumer-id at the gateway for per-consumer call counts and HTTP 429. The default mock usage stays below REQ 60's 300 tokens/min budget; bump Calls per consumer high enough and limited_calls / Loki status=429 lines will increase.

Reference commands

Direct port-forward to the Limitador metrics endpoint (no auth required):

oc -n kuadrant-system port-forward svc/limitador-limitador 18080:8080 &
curl -s http://localhost:18080/metrics | grep -E '^authorized_|^limited_'

Same query via Thanos:

TOKEN=$(oc create token prometheus-k8s -n openshift-monitoring)
THANOS=$(oc -n openshift-monitoring get route thanos-querier -o jsonpath='{.spec.host}')
curl -sk -H "Authorization: Bearer $TOKEN" \
  "https://$THANOS/api/v1/query?query=authorized_hits" | jq .

PromQL — Grafana dashboard RHCL AI Token Usage:

sum(increase(authorized_hits{limitador_namespace="rhcl-apps/banking-api-connectivity"}[$__range]))
sum(rate (authorized_hits{limitador_namespace="rhcl-apps/banking-api-connectivity"}[5m])) * 60
sum(increase(limited_calls   {limitador_namespace="rhcl-apps/banking-api-connectivity"}[$__range]))

LogQL — Grafana dashboard RHCL AI Consumer Access Logs:

sum by (consumer) (count_over_time({job="rhcl-gateway"} |= "RHCL_ACCESS" | regexp `consumer=(?P<consumer>[^ ]+)` | regexp `path=(?P<path>[^ ]+)` | path="/api/v1/chat/completions" | consumer!="-" [1h]))
sum by (consumer) (rate({job="rhcl-gateway"} |= "RHCL_ACCESS" | regexp `status=(?P<status>[^ ]+)` | status="429" [5m])) * 60
{job="rhcl-gateway"} |= "RHCL_ACCESS" | regexp `consumer=(?P<consumer>[^ ]+)` | consumer="alice-req40"

Confirm gateway RHCL_ACCESS logs (EnvoyFilter):

GW=$(oc -n openshift-ingress get pods -l gateway.networking.k8s.io/gateway-name=rhcl-apps-gateway -o jsonpath='{.items[0].metadata.name}')
oc -n openshift-ingress logs "$GW" -c istio-proxy --tail=5 | grep RHCL_ACCESS
