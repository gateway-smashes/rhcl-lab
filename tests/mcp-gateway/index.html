REQ 59 — MCP Gateway

MCP Gateway (dedicated Istio Gateway)

Smoke-test Streamable HTTP MCP against http://mcp-gateway.<RHCL_ZONE_ROOT_DOMAIN>:8080/mcp on the dedicated Gateway rhcl-mcp-gateway in namespace mcp-gateway. Tools are broker-prefixed (e.g. banking_getAccountSummary).

Scenario

Browser (this page)
        │  POST /mcp  JSON-RPC + Accept: application/json, text/event-stream
        ▼
http://mcp-gateway.<RHCL_ZONE_ROOT_DOMAIN>:8080/mcp
        │  Gateway rhcl-mcp-gateway (Istio, listener `mcp`)
        │  HTTPRoute mcp-gateway-route-custom (CORS)
        ▼
MCPGatewayExtension → broker mcp-gateway:8080
        │  MCPServerRegistration → banking-api-mcp-server (listener `mcps`)
        ▼
Service banking-api-v1:8080  →  Quarkus MCP server

Isolated from rhcl-apps-gateway. Install via automation/playbooks/mcp_gateway-install.yml or manifests 10–46 under manifests/.

Controls

mcp-session-id: (none — run Initialize)

Install (oc + jq + envsubst)

From the repository root, after export RHCL_ZONE_ROOT_DOMAIN=…. The CORS overlay needs the dynamic index of the /mcp rule; the EnvoyFilter needs the gateway vhost name. 

export RHCL_ZONE_ROOT_DOMAIN=apps.example.com

export MCP_RULE_INDEX="$(
  oc -n rhcl-apps get httproute banking-api-connectivity -o json \
  | jq '[.spec.rules[] | .matches[0].path.value] | index("/mcp")'
)"

envsubst < tests/mcp-gateway/manifests/50-mcp-cors-overlay.patch.json \
  | oc -n rhcl-apps patch httproute/banking-api-connectivity \
       --type=json --patch-file=/dev/stdin

oc -n rhcl-apps patch authpolicy/banking-api-connectivity-apikey \
   --type=json --patch-file=tests/mcp-gateway/manifests/51-mcp-anonymous-authpolicy-patch.json

# Discover gateway vhost and apply the CORS preflight EnvoyFilter (204 short-circuit)
GW_POD="$(oc -n mcp-gateway get pods \
  -l gateway.networking.k8s.io/gateway-name=rhcl-mcp-gateway -o name | head -1)"
oc -n mcp-gateway port-forward "$GW_POD" 15000:15000 >/tmp/pf.log 2>&1 &
PF=$!; sleep 2
export RHCL_MCP_VHOST="$(
  curl -s http://localhost:15000/config_dump \
  | jq -r '.configs[]|select(."@type"|test("RoutesConfigDump"))|.dynamic_route_configs[]?.route_config.virtual_hosts[]?.name' \
  | grep banking-api-connectivity | grep ':443$' | head -1
)"
kill $PF 2>/dev/null

envsubst < tests/mcp-gateway/manifests/52-mcp-cors-preflight-envoyfilter.yaml | oc apply -f -

  oc -n rhcl-apps wait httproute/banking-api-connectivity \
   --for=condition=Accepted=True --timeout=2m

curl reference

export RHCL_ZONE_ROOT_DOMAIN=apps.example.com
export MCP_URL="https://banking-api-connectivity.${RHCL_ZONE_ROOT_DOMAIN}/mcp"

curl -si -H 'content-type: application/json' \
  -H 'accept: application/json, text/event-stream' \
  --data '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"curl","version":"1"}}}' \
  "$MCP_URL"
