req026 — Streaming de arquivos (RHCL body cap)

Gera bytes aleatórios localmente e envia pra /api/files/upload. O gateway RHCL aplica um cap de 32 MiB via Envoy Lua streaming filter (contagem chunk-a-chunk, não buferiza o request) + timeout de 60 s via HTTPRoute. Uploads acima do cap voltam com HTTP 413 e os headers x-rhcl-streaming-cap + x-rhcl-observed-bytes.

cap = 32 MiB timeout = 60 s Esperado: 1/25 MiB → 200 com SHA-256. 50 MiB → 413 (rejeição RHCL).
